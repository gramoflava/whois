# whois

Who lava is: a one-page profile with a short bio and live list of public
projects from GitHub.

Live at [whois.gramoflava.xyz](https://whois.gramoflava.xyz). Static HTML on
GitHub Pages, no build step, no backend. The projects list is read from the
GitHub API in the visitor's browser.

## Design

Built on [gramof design](https://github.com/gramoflava/gramofdesign), vendored
in `gramofdesign/`. Read `AGENTS.md` before changing anything visual.
